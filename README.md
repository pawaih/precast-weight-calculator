# Precast Weight Calculator

Web calculator for the lifting weight of one precast unit (based on Precast_Weight_Calculator_V2.0).

**Weight (tonne) = (concrete volume × density + rebar kg + BRC mesh kg) ÷ 1000**

- Concrete: by L × W × T (m) or volume (m³), with deductions for openings
- Rebar: bar marks AS01–AS20, bar size, nos and cut length (m)
- BRC mesh: A6–A10 or custom kg/m², sheet size (m)
- Default concrete density 2406.53 kg/m³; bar weight table can be edited
- Save PDF, copy summary, clear entries; inputs are saved in the browser

## Use it

Open `index.html` in a browser, or turn on GitHub Pages:
Settings → Pages → Source: *Deploy from a branch* → `main` / root → Save.
The calculator will be at `https://pawaih.github.io/precast-weight-calculator/`.
